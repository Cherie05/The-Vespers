# Contributing to VesperAero

We welcome contributions from researchers, environmental scientists, engineers, and open-source developers worldwide.

## Development Workflow

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/Cherie05/The-Vespers.git
   cd The-Vespers
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the monorepo locally:
   ```bash
   npm run dev
   ```
5. Run the security & test suite before submitting:
   ```bash
   npm test
   ```
6. Create a feature branch and open a Pull Request against `main`.
